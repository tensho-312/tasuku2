GitHub (`libraryapp`) & Firebase Hosting 公開の手順

1. GitHubにリポジトリを作成して送信 

git init
git add index.html
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/ユーザー名/libraryapp.git
git push -u origin main

2. Firebase Hostingでインターネット公開 

npm install -g firebase-tools
firebase login
firebase init hosting
# プロジェクト: tasuku2-199b1 を選択
# Public directory: .
# Single-page app: y
firebase deploy
